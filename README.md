# 🗂️ Weapon Images Repository

Questa repository contiene le immagini PNG delle armi utilizzate dal bot Discord per mostrare le statistiche in embed.

## 📁 Struttura

- Tutte le immagini sono salvate nella cartella `weaponsIMG/`
- I file hanno nome **esattamente corrispondente** al nome dell’arma, in **maiuscolo**, con estensione `.png`  
  Esempi:
  - `AK47.png`
  - `M60.png`
  - `CB-01 REPEATER.png`

## 🌐 Hosting via GitHub Pages

Questa repo è configurata per essere servita tramite GitHub Pages.
